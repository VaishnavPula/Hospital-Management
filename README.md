# 🏥 CityCare Hospital Management System

A web-based Hospital Management System developed using Python, Flask, SQLite, HTML, CSS, and JavaScript.

The application simplifies hospital operations by managing patient records, doctor information, appointments, and billing through a user-friendly interface.

## 🚀 Run

1. Open this folder in VS Code.

2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Create a `.env` file in the project folder and configure the required environment variables.

4. Run the Flask application:

```bash
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000/
```

## 🗄️ Database

The application uses SQLite to store and manage hospital information.

The database supports:

- Patient records
- Doctor details
- Appointment information
- Billing records

## 🔄 How It Works

1. Users access the hospital management dashboard.
2. Patient information can be added and managed.
3. Doctor details can be maintained.
4. Appointments can be scheduled and tracked.
5. Billing information can be managed.
6. Data is stored in an SQLite database.

## 🎯 Project Objective

The objective of this project is to develop a simple and efficient hospital management application that reduces manual record management and organizes hospital operations through a centralized web interface.
