# CityCare Hospital Management System

A simple Flask + SQLite Hospital Management System.

## Run

1. Open this folder in VS Code.
2. Install packages:

```bash
pip install -r requirements.txt
```

3. Keep the `.env` file in the project folder.
4. Run:

```bash
python app.py
```

5. Open:

```text
http://127.0.0.1:5000/
```

## Features

- Dashboard
- Patient management
- Doctor management
- Appointment management
- Billing
- SQLite database
- Simple HTML, CSS and JavaScript
- Light/dark mode

The HTML files are normal HTML files. They do not use Jinja template syntax.
